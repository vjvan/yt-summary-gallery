# Discord 網頁直播翻譯：本機第一版

## 這一版做什麼

在 **桌面版 Chrome 的 Discord 網頁** 聆聽直播，手動啟用 YT Summary 擴充功能，將該分頁的英文音訊送到自己電腦的 Whisper 辨識，再以 Ollama 翻成台灣繁體中文。在本機 `/live` 翻譯台並排看雙語逐字稿；輸入中文，可以產生可修改、複製的英文回覆草稿。

這不是零延遲字幕，也不是 Discord 官方字幕功能。翻譯必須等到一小段語音及推論完成；速度取決於說話長度與本機負載。此版不提供講者分離、不處理 Mac Discord App、不替你加入頻道、不自動發送文字或語音。

## 使用順序

1. 保持本機服務執行：專案目錄執行 `npm run watch:local`。在 `http://127.0.0.1:3000/live` 確認本機翻譯及語音辨識皆就緒。服務沒有啟動時，Chrome 擴充功能無法單獨翻譯。
2. 在 `chrome://extensions` 重新載入本專案的 `extensions/yt-summary-watch`；這版加入 Discord 支援，若 Chrome 要求新增網站權限，由你確認。更新擴充功能不會自動同意收音。
3. 若還沒配對：在本機 `/watch` 按「顯示本機配對碼」，再從 Chrome 工具列的拼圖按鈕打開 YT Summary 擴充功能，把碼貼入其配對碼欄位並儲存。配對碼只用來授權擴充功能連到你的本機服務；不要傳給別人，不是雲端 API 金鑰。
4. 回到 `https://discord.com/channels/...`，自行進入你有權限聆聽的頻道，播放直播。打開擴充功能，確認收音來源及說明、勾選本次同意，再開始直播翻譯。
5. 開啟 `/live` 翻譯台與 Discord 並排。切換到翻譯台不會切換收音來源：仍持續收原來那個 Discord 分頁，直到停止。右側輸入中文、產生英文草稿、修改後複製；由你自行貼入 Discord 並決定是否送出。
6. 結束時按停止。關閉來源分頁、離開原頻道、音訊權限失效或處理佇列過載也會停止。從翻譯台按停止時，擴充功能會在下一次狀態檢查時關閉音軌（正常約 2 秒）。

## 隱私與費用

- 每次收音都要手動啟動。請事先確認參與者及頻道規範允許音訊轉錄。
- 擷取的是分頁的混合聲音，可能包含多人與通知；不是只錄目前畫面中的講者。沒有使用麥克風，也不錄影。
- Live 後端只允許本機模式；模型失效不會偷偷切換雲端。辨識、翻譯、回覆草稿不產生雲端 API 呼叫費用，但會使用你的 CPU/GPU、記憶體和電力。Discord 播放本身仍需要網路。
- 原始音訊不做長期保存，處理用暫存檔會清除。直播近期逐字稿及草稿保留於伺服器記憶體，不寫入影片庫；停止不等於立刻抹除畫面中的近期內容，伺服器重啟或工作過期後消失。
- 直播逐字稿、草稿可能包含機密，請勿將畫面或配對碼公開分享。

## 「分片」不是「總次數上限」

直播必須分成短音訊片段，才能一邊持續收下一段、一邊辨識前一段；一次送完整直播會無法邊看邊翻。

本機直播模式沒有「每片最多翻譯 25 批」這類總批數限制。仍有必要的單次大小、排隊時間、同時處理數與近期記憶體保留量限制，避免電腦負載爆增。

- 單片長度限制：保障解碼與推論可控，不代表直播只能看這麼久。
- 音訊佇列有界：若模型長期追不上直播，介面會顯示失敗／未處理內容並停止，而不是無限累積或假裝所有字幕都成功。
- 最近 100 個音訊片段／500 段字幕是畫面與記憶體保留量，不是整場直播的翻譯總額度。
- 安靜片段可以略過；這不代表遺失人聲。實際雜訊、很小聲或多人重疊仍可能造成漏辨或誤辨，重要回覆請自行核對。

## 開發驗收

- `npm run test:watch`：包含舊 YouTube、API 安全與新 Live 分片／佇列／UI 測試。
- `npx tsc --noEmit`、`npm run build`：型別與建置。
- `/live?demo=1`：純示例，不呼叫模型、不收音；`/live/mobile-preview`：440 × 956 手機版預覽。手機預覽不表示 iPhone Chrome 能安裝桌面擴充功能。
- 真實 Discord 聲音的端到端驗收，必須由使用者在 Discord Chrome 分頁手動同意啟用；合成音訊及公開語音 fixture 測試不能替代這個驗收。

官方參考：[Chrome tabCapture](https://developer.chrome.com/docs/extensions/reference/api/tabCapture)、[Chrome 背景分頁音訊擷取](https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture)。
